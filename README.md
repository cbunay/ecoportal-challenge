# ecoPortal calendar

Next.js app for the ecoPortal front-end challenge. The current screen is a static calendar shell: sidebar, toolbar, and main area. The toolbar shows the current month. The buttons do not change the view yet.

## Setup

```bash
npm install
npx playwright install chromium
```

## Scripts

- `npm run dev` — app at http://localhost:3000/calendar
- `npm test` — unit tests
- `npm run test:e2e` — Playwright
- `npm run lint` — ESLint
